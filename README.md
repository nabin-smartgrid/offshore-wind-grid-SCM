# WindGrid — 해상풍력 계통연계 · 공급망 영향 분석

곽나빈님의 스마트그리드 개인 프로젝트 계획에 따른 교육용 프로토타입입니다.
**계산은 코드, 해석은 LLM**이라는 원칙과 5개 화면 구조를 적용했습니다.
실제 프로젝트의 설계·발주·계통 적합성 판정을 위한 프로그램은 아닙니다.

## 먼저 화면부터 보기

`BROWSER_APP.html`을 Chrome 또는 Edge에서 엽니다.

- 처음 나타나는 화면은 **설치 없이 동작하는 HTML/JavaScript 체험판**입니다.
  숫자 변경, 5개 화면 이동, 텍스트 문서 등록·검색, 보고서 저장을 직접 조작할 수 있습니다.
- 위쪽 **Streamlit로 실행**을 누르면 Stlite가 Python 코드를 브라우저에서 실행하도록 구성했습니다.
  이때만 외부 CDN에서 Streamlit/Pyodide 실행 엔진과 pypdf를 읽습니다.
  인터넷 연결이 필요하며 회사 보안망에서는 차단될 수 있습니다.
- 실행 엔진을 불러오지 못하면 **체험 화면으로** 돌아갈 수 있습니다.
- 브라우저판에는 API 키를 입력하지 않습니다. 실제 LLM 연동은 아래 Python 서버판에서 설정합니다.
- HTML 체험판과 Streamlit 브라우저판은 서로 다른 실행 환경입니다. 각자의 입력·문서 상태가
  자동으로 동기화되지는 않으며 전환 시 Streamlit은 기본 예시부터 시작합니다.

## 실제 Python Streamlit 앱 실행 — Windows

1. ZIP을 먼저 압축 해제합니다. ZIP 내부에서 바로 실행하지 마세요.
2. Python 3.11 이상이 설치되어 있어야 합니다. 새로 설치할 때 `Add Python to PATH`를 선택합니다.
3. `RUN_WINDOWS.bat`을 더블클릭합니다.
4. 최초 실행 때 필요한 패키지를 설치한 뒤 브라우저가 열립니다. 인터넷 연결이 필요합니다.
5. 종료하려면 실행 창에서 Ctrl+C를 누릅니다.

자동 실행이 어려우면 해당 폴더의 터미널에서:

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m streamlit run app.py
```

macOS/Linux:

```bash
bash RUN_MAC_LINUX.sh
```

공개 웹 주소에 배포하지 않은 로컬 실행용 파일입니다. 서버가 실행되는 컴퓨터의 브라우저에서 사용합니다.
회사 보안 정책과 설치 권한을 확인하세요.

## 화면 구성

| 화면 | 구현 내용 |
|---|---|
| ① 프로젝트 입력 | 정격용량, 케이블 길이, 전압, 연계 방식, 단락용량, COD와 세부 가정 |
| ② 근거 문서 | 과제 계획 발췌 + 공개 PDF/TXT/MD 업로드, 텍스트 추출과 키워드 검색 |
| ③ 분석 진행 | 입력 검증 → 계산 → 예시 판정 → 기자재 후보 → LLM의 실제 처리 상태 |
| ④ 분석 결과 | Qc, 부하전류 저항손실, SCR, 길이 비교, 기자재/SCM 확인사항 |
| ⑤ AI 보고서 | 템플릿 보고서 저장, 선택적 실제 Gemini 요청, 인용 ID 존재 검사 |

결과 화면을 먼저 보여주도록 초기 메뉴를 ④로 설정했습니다.
입력값을 바꾼 후 **입력 적용 · 분석 실행**을 눌러 적용합니다.

## 출처와 구현에서 추가한 가정

### 제출 보고서에 근거한 내용

기초 자료는 사용자가 제공한 `스마트그리드_관심영역_소개보고서_곽나빈.docx`입니다.
원본 파일 전체 또는 회사 내부 문서는 이 배포본에 포함하지 않았습니다.

- §2: `Qc = V_LL² × (2πf) × C_phase × length`의 간이식 및 C=0.2 μF/km의 가정 예시.
- §2: 케이블 무효전력과 리액터, 무효전력 요건과 WTG/STATCOM, 계통 이슈와 기자재 매핑.
- §4: 코드 계산 → 규칙 → 기자재 매핑 → 문서 기반 LLM 해석, Streamlit의 5개 화면.
- §5: 정상상태 간이 모델, 동적 해석 제외, 공개 자료 사용, 계산과 AI 해석을 분리 검증.

내장 PLAN-2, PLAN-4, PLAN-5 발췌는 **과제 계획**이며 공인 기술기준이 아닙니다.
공개 Grid Code 또는 제조사 데이터시트는 아직 내장하지 않았습니다.

### 이번 구현에서 명시적으로 추가한 간이 가정

- 기본값: 500 MW, 65 km, 154 kV, 단락용량 1,400 MVA, 동일 병렬 2회선.
- 정전용량 0.2 μF/km, 상별 저항 0.03 Ω/km, 주파수 60 Hz, 역률 1.0.
- C와 R은 **상별·km당 값**입니다. 전압은 **선간 RMS**입니다.
- 동일 회선 수 n에 대해 Qc를 n배 합산하고 유효전력은 회선 간 동일 분담합니다.
- `I = P/(√3 × V_LL × PF × n)`
- `P_loss = n × 3 × I² × R_phase × length`
- `SCR = short_circuit_MVA / plant_rated_MW`
- 수업용 예시 등급: Qc/정격MW 경계 0.20·0.40, 부하전류 저항손실률 1%·3%, SCR 2·3.
  이 경계는 **가정**으로, 허용 기준이나 공인 위험등급이 아닙니다. 체크박스를 끄면 판정 보류로 표시합니다.

이전 이미지에 그려진 48.6 Mvar, 2.9% 등을 답으로 고정하지 않았습니다.
모든 표시값은 위 입력·산식으로 다시 계산합니다.

### 기본 예시의 코드 계산값

- 회선당 Qc: 116.229378 Mvar
- 2회선 합계 Qc: 232.458755 Mvar
- 회선당 부하전류: 937.256931 A
- 부하전류 성분 저항손실: 10.277871 MW / 운전 유효전력 대비 2.055574%
- 단순 SCR: 2.8

**Qc는 리액터 발주 용량이 아닙니다.**
**위 손실은 전체 송전손실이 아닙니다.** 충전전류, 시스, 유전체, 변압기, 컨버터 손실은 제외했습니다.
무부하라도 케이블이 가압되어 있으면 Qc 계산값은 남지만, 본 모델의 부하전류 저항손실은 0으로 표시됩니다.
이것은 실제 무부하 손실이 0이라는 뜻이 아닙니다.
VSC-HVDC에는 AC 케이블 식을 적용하지 않으며 해당 항목을 0이 아닌 미산출로 표시합니다.

## 실제 LLM 연결 (선택)

Python 서버판의 ⑤ AI 보고서 → LLM 연결을 펼칩니다.
Gemini API 키와 계정에서 사용 가능한 모델 ID를 입력합니다.
전송할 계산·입력값과 검색된 발췌를 확인하고, **공개 자료 전송 동의** 후 생성 버튼을 누릅니다.
추가 API 비용이 발생할 수 있습니다.

- API 키는 소스에 하드코딩하거나 URL, 보고서, 로그에 넣지 않습니다.
- API 키는 해당 세션 또는 사용자가 설정한 환경변수에 존재합니다.
- 보고서 입력·선택한 문서 발췌만 Google의 generateContent 엔드포인트로 전송합니다.
- 업로드만으로 API를 자동 호출하지 않습니다.
- 입력 또는 문서가 바뀌면 기존 AI 결과를 폐기하여 다른 시나리오의 설명이 남지 않게 했습니다.
- API 미연결 시에는 **규칙 기반 템플릿**이라고 표시합니다.
- 인용 검사는 문서 ID의 존재만 확인합니다. 주장의 정확성·문서 최신성은 사람이 원문 대조해야 합니다.
- 키워드 검색은 초기 문서검색 모듈이며, 임베딩 기반 RAG가 완성되었다고 주장하지 않습니다.

## PDF와 자료 저장

Python판은 ReportLab으로 PDF를 생성합니다. 설치된 한국어 글꼴을 사용하고, 없으면 CID 글꼴로 대체합니다.
한글 표시 문제가 있으면 `KOREAN_FONT_PATH` 환경변수로 로컬 TTF 경로를 지정하거나
HTML 보고서를 열어 브라우저의 **인쇄 → PDF로 저장**을 사용하세요. 글꼴 파일은 배포하지 않습니다.
브라우저판은 HTML 보고서 / 인쇄 → PDF 저장을 제공합니다.
입력·계산값은 JSON으로 저장할 수 있습니다.
문서는 세션 메모리에만 보관하며 분석 이력 DB, 로그인, 영구 저장소는 없습니다.

## 검증 범위 — 중요한 구분

- `python -m unittest discover -s tests -v`: 계산·입력 검증·텍스트 추출·인용 검사·보고서 등 **20개 테스트 통과**.
- HTML 체험판: Chromium에서 입력 변경, 재계산, 5화면 이동, 텍스트 업로드·검색,
  JSON/HTML 저장, 모바일 가로 넘침, 네트워크 차단 시 복귀 동작을 확인했습니다.
- 기본값 및 길이 변경에서 JavaScript 체험판과 Python 계산값이 일치함을 확인했습니다.
- Python 생성 PDF 2쪽과 브라우저 인쇄 PDF를 렌더링해 확인했습니다.
- **제작 환경에 Streamlit이 없고 패키지 설치용 네트워크가 막혀 있어 실제 Streamlit 서버는 실행 검증하지 못했습니다.**
- **Stlite 실행 엔진의 외부 다운로드도 이 환경에서 검증하지 못했습니다.**
- **Gemini API는 키 없이 제작했으므로 실제 API 호출·품질 검증은 미수행입니다.**
- 실계통 조류계산 또는 제조사 결과와의 교차 검증은 미수행입니다. 단위·대수 관계 테스트만으로
  실제 설계 모델이 검증되었다고 볼 수 없습니다.

`TEST_RESULTS.txt`에 실제 실행한 테스트 기록을 포함했습니다.

## 개발 파일

- `app.py`: 실제 Streamlit UI
- `core.py`: 독립적인 계산 및 예시 판정
- `evidence.py`: 문서 추출·검색·선택적 API 요청
- `reporting.py`: Markdown/HTML/PDF 보고서
- `BROWSER_APP.html`: 설치 없는 체험판 + Stlite 실행 진입점, Python 소스 내장
- `tests/test_core.py`: 독립 테스트
- `requirements.txt`, `.streamlit/config.toml`: 설치 및 화면 설정
- `RUN_WINDOWS.bat`, `RUN_MAC_LINUX.sh`: 로컬 실행 스크립트
